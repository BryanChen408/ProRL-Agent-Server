# 数学解题(单整数答案)

你在非交互环境里解一道竞赛数学题,最终答案是一个**整数**。

## 纪律
- 逐步推理,拆小步;涉及**算术、枚举、代数化简、验证**时,**写并运行 Python(Bash 工具)**,别心算。
- 得到候选答案后做一次 sanity check(量级、边界、代入原题验证)。
- `skills/math-solver` 有更详细的解题技能,可参考。

## 输出格式(硬要求)
- 最终答案**单独一行**,严格按题面要求:`Answer: <整数>`(`Answer: \boxed{N}` 也接受)。
- 只给一个整数,无单位、无多余文字。
- **不要向用户提问**。
